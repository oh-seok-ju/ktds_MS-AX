# 🛡️ 'SecureAI Assistant' - AI 보안 교정

**"AI가 콘텐츠의 보안 위반 여부를 감지하고 조치까지 제안해주는 보안 교정 시스템"**


## 1. ✅ 프로젝트  개요 
 
### 🚨 해결하고자 하는 문제

| 문제점 | 설명 |
| --- | --- |
| 🔑 **하드코딩된 민감정보** | API 키, 비밀번호, 토큰이 코드에 직접 포함 |
| 📧 **개인정보 유출** | 메일/메시지에 주민등록번호, 카드번호 등 실수로 포함 |
| 📚 **정책 미준수** | 내부 보안 정책에 대한 인지 부족 |

### 프로젝트 요약
>
> 사용자가 작성한 메일, 메시지 등 텍스트에 대해 또는, 업로드한 파일(코드, 로그, PDF 파일 등)에 대해
>
>**보안 위반 사항이나 개인정보 유출 가능성**을 위험을 탐지하고, **자동 분석·경고·수정 제안**까지 해주는 **AI 보안 교정 시스템**
>

 ---

## 2. 🎯 기능 및 흐름

### 주요 기능
1. 정규식 기반 빠른 서치 
	- Blob Storage에 저장된 정규식(룰)기반으로 보안 검사 진행
	- 검사 결과 및 해당 항목에 대한 해결 방안까지 추가 제안
2. 내부 정책 문서 기반 검사(ai)
	- Ai Search index 기반 키워드 기반으로 AI 보안 검사 진행
	- 내부 정책에 문제가 되는 항목에 대해서 해결 방안 제공 
3. 하이브리드 검사(ai)
	- 내부 정책문서 뿐만 아니라 AI가 자료 조사 및 판단한 근거로 보안 검사 진행
	- 검사 결과 및 해당 항목에 대한 해결 방안 출처까지 제공
4. 기타
   - 파일 업로드 -> blob Storage -> index 업데이트를 통한 내부 보안 정책 실시간 업데이트


```

                         │

                         │────────────── │   데이터(정책) 관리 │
                         │               │   업로드 파일 관리  │      
                         │               └────────────────────┘
                         │
                   ┌───────────────┐
                   │               │             
			┌──────▼───┐      ┌────▼──────┐     
			│ Rule-    │      │ Azure AI  │

			│ Filter   │      │           │
			└──────────┘      └───────────┘
                      │               │──────────────────────────┐ 
                      │         ┌─────▼───────────────┐      ┌───▼────────────────┐
                      │         │  Azure OpenAI GPT-4 │      │ Azure OpenAI GPT-4 │
                      │         │  (gpt-4.1-mini)     │      │  (gpt-4.1-mini)    │
                      │         │  RAG(내부정책 강제)  │      │  RAG(AI 자율성)    │ 
                      │         │  (수동/키워드 주입)  │      |  (자동/Extrabody)  │
                      │         └─────────────────────┘      └────────────────────┘

					└────────────────────────┘ 
					

```

| 서비스 | 역할 |

| **Azure Blob Storage**      |      파일 저장소 | 
| **Azure App Service**      |      웹 호스팅 |
