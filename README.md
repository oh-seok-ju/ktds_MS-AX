# AI 보안 교정(Governance) Assistant
https://pro-osj-web13.azurewebsites.net/

**"AI가 실시간으로 콘텐츠의 보안 위반 여부를 감지하고 조치까지 제안해주는 보안 감사 Agent"**

### ✅ **요약**

> 사용자가 작성한 메일, 메시지, 코드, 문서, 프롬프트 등 텍스트에 대해,
> 
> 
> **보안 위반 사항이나 개인정보 유출 가능성**을 위험을 탐지하고,
> 
> **자동 분석·경고·수정 제안**까지 해주는 **AI 보안 교정 시스템**
> 

문제 정의, 대상 사용자, 솔루션 개요

---
### 🎯 **적용 예시 시나리오**

1. **메일 작성 시**
    - 사용자: "김과장님, 고객 홍길동 주민번호 900101-1234567는 꼭 비밀로 부탁드립니다."
    - 시스템: ⚠️ 주민번호 포함 → 민감정보 포함 경고 + 수정 제안
2. **코드 작성 시**
    - 사용자: `"API_KEY = 'sk-abc123-real-secret'"`
    - 시스템: ⚠️ 실제 API 키 감지됨 → 플레이스홀더로 대체 제안
    - 시스템: 제안 > os.getenv("key") 형식으로
