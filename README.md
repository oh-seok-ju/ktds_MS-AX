# 🛡️ 'SecureAI Assistant' - AI 보안 교정

**"AI가 콘텐츠의 보안 위반 여부를 감지하고 조치까지 제안해주는 보안 교정 Agent"**


## 1. ✅ 프로젝트  개요 

### 프로젝트 요약
- 사용자가 작성한 메일, 메시지 등 텍스트에 대해, 혹은 업로드한 파일(코드, 로그, PDF 파일 등)에 대해,
- **보안 위반 사항이나 개인정보 유출 가능성**을 위험을 탐지하고,
- **자동 분석·경고·수정 제안**까지 해주는 **AI 보안 교정 시스템**
 
### 현재 문제점
- 개발자/직원들이 무심코 코드에 API 키, 비밀번호 하드코딩
- 메일/메시지에 개인정보(주민등록번호, 카드번호) 실수로 포함
- 보안 정책 위반 사항을 사후에 발견 → 이미 유출된 후
- 수동 검사는 시간이 오래 걸리고 일관성 부족
